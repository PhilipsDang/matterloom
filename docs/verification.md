## 自动化覆盖

- 多页 PDF 的文件页序号及对应文字。
- 同一事项重复内容去重，跨事项独立保留。
- 数据库重新打开后原件和解析结果仍在。
- 损坏、空文件、超大文件、不支持格式及加密 PDF。
- DOCX 段落和表格单元格的顺序与定位。
- 纯扫描页和文本／扫描混合 PDF 的部分成功状态。
- OCR 失败后保留原页。
- 重新解析不重复生成原文单元。
- 中断状态恢复及重试。
- 文件名不决定磁盘目录，原件使用内部编号保存。
- HTTP 中文文件名上传、页面图像输出、事项隔离和请求来源校验。
